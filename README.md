# The Earth Mitra — Frontend

Plain Vite + React (JavaScript / JSX, no TypeScript) frontend, converted from the Figma Make design.

## Stack
- React 19
- React Router 7
- Vite
- Tailwind CSS 4

## Getting started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
